# Journal d'usage de l'IA (R3)

Ce dossier trace chaque session de travail avec un outil d'IA. Une fiche par
session, avec la regle du carnet de bord :

- **garde tel quel** : code/prompt utilise sans modification.
- **corrige a la main** : l'IA a produit quelque chose, je l'ai modifie.
- **reecrit** : j'ai remplace le code/prompt de l'IA par le mien.

Regle de securite : aucune cle API, aucun mot de passe, aucune donnee
personnelle n'a ete collee dans un prompt ou dans le depot.
